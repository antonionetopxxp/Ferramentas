# 🇺🇸 Ferramentas USA

Site estático profissional para divulgar ferramentas de IA, tecnologia, produtividade e links de afiliado.

## Arquivos
- `index.html` — estrutura e conteúdo
- `style.css` — visual, responsividade e animações
- `script.js` — filtros, busca, menu mobile, animações ao rolar e interações

Não usa framework ou biblioteca externa.

## GitHub + Netlify
Suba os três arquivos na raiz do repositório. No Netlify, importe o repositório, deixe o comando de build vazio e use `/` como diretório de publicação.

## Links de afiliado
No `index.html`, troque `href="#"` dos cards pelo link rastreável da Awin. Recomendo usar:
`target="_blank" rel="sponsored noopener"`

## Próximo nível
Depois que os primeiros programas forem aprovados, podemos criar cards reais com logo, preço/oferta, avaliações, páginas individuais, SEO, Open Graph, analytics e uma área de ofertas.
