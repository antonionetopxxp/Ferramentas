# 🇺🇸 Ferramentas USA

Site responsivo para divulgar **IA, tecnologia, produtividade e negócios**, com foco em seguidores, descoberta de ferramentas e monetização por afiliados.

## Arquivos
- `index.html` — estrutura e conteúdo
- `style.css` — visual, responsividade e animações
- `script.js` — filtros, pesquisa, favoritos, menu mobile e interações

## Netlify
Conecte o repositório GitHub ao Netlify. Não há build: o site usa HTML/CSS/JavaScript puro e o `index.html` é a entrada.

## Links de afiliado
No `script.js`, troque os botões `Conhecer` para apontar para seus links de afiliado. Antes de publicar, revise as regras do programa de afiliados e mantenha o aviso de transparência no rodapé.

## Próximos passos
1. Trocar os `#` das redes sociais pelos seus perfis.
2. Colocar seus links reais de afiliado.
3. Adicionar logo/imagens próprias quando quiser.
4. Ligar o formulário a uma plataforma de e-mail.
5. Adicionar Google Analytics/Meta Pixel se necessário.
